# CrewAI Multi-Agent System

## Опис проєкту

Навчальний проєкт у межах лабораторної роботи № 4 з дисципліни «Інтелектуальні автономні системи».

Мета проєкту — реалізувати багатоагентну систему на основі CrewAI з ролями Delegator, Worker і Coordinator та порівняти її роботу з одноагентним підходом.

## Використані технології

- Python 3.12
- CrewAI
- Ollama
- Llama 3
- Gemini API
- python-dotenv
- ddgs
- google-genai

## Архітектура

Система містить три агенти:

- **Delegator** — формує план маркетингової кампанії.
- **Worker** — створює рекламні тексти та ідеї публікацій.
- **Coordinator** — перевіряє й редагує результати попередніх етапів.

Delegator і Worker використовують локальну модель Llama 3 через Ollama. Coordinator використовує Gemini API.

Завдання виконуються послідовно, а результати попередніх завдань передаються наступним через контекст CrewAI.

## Вимоги

- Python 3.12 або сумісна версія.
- Встановлений Ollama.
- Завантажена модель `llama3:latest`.
- API-ключ Gemini.

## Встановлення та налаштування

1. Клонуйте репозиторій або завантажте його архів.
2. Перейдіть до каталогу проєкту.
3. Створіть і активуйте віртуальне середовище:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

4. Встановіть залежності:

```powershell
python -m pip install -r requirements.txt
```

5. Переконайтеся, що Ollama доступна та модель завантажена:

```powershell
ollama pull llama3:latest
ollama list
```

6. Створіть локальний файл `.env` на основі `.env.example`. Заповніть його власним API-ключем Gemini та налаштуваннями моделі.

Приклад конфігурації:

```dotenv
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-3.8-flash
OLLAMA_MODEL=llama3:latest
```

Не публікуйте справжній API-ключ. Файл `.env` не повинен потрапляти до Git-репозиторію.

## Запуск

Основна багатоагентна система:

```powershell
python main.py
```

Одноагентний сценарій для порівняння:

```powershell
python baseline.py
```

Перевірка Gemini API:

```powershell
python test_gemini.py
```

Перевірка простого агента Ollama:

```powershell
python test_agent.py
```

## Безпека

- Файл `.env` містить секретні налаштування та API-ключ і не повинен публікуватися.
- Віртуальне середовище `.venv` не додається до репозиторію.
- Для налаштування використовуйте `.env.example` без справжніх секретів.
